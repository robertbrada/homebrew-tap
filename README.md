# Homebrew tap for MacAway

[MacAway](https://macaway.app) locks your Mac when your iPhone or Apple Watch moves away.

```bash
brew install --cask robertbrada/tap/macaway
```

MacAway updates itself, so `brew upgrade` leaves it alone. It is free for 14 days, then a
one-time purchase at [macaway.app](https://macaway.app).
